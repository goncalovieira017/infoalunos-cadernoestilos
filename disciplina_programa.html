Conteúdos Programáticos

Lista detalhada dos tópicos abordados nesta unidade curricular.

1. Introdução aos Sistemas de Bases de Dados
  • Definição de Base de Dados e SGBD.
  • Vantagens da utilização de SGBDs.
  • Níveis de abstração (Físico, Lógico, Vista).
  • Modelos de dados (Relacional, Hierárquico, Rede, NoSQL).
2. Modelação Conceptual (Modelo ER)
  • Entidades e Atributos.
  • Relacionamentos e Cardinalidade (1:1, 1:N, N:M).
  • Atributos compostos e multivalor.
  • Entidades Fracas.
  • Diagramas Entidade-Relacionamento Estendidos (EER).
3. Modelo Relacional e Normalização
  • Relações, tuplos e domínios.
  • Chaves Primárias (PK) e Chaves Estrangeiras (FK).
  • Conversão do Modelo ER para o Modelo Relacional.
  • Dependências Funcionais.
  • Formas Normais (1FN, 2FN, 3FN, BCNF).
4. Linguagem SQL (Structured Query Language)
  • DDL: CREATE, ALTER, DROP TABLE.
  • DML: INSERT, UPDATE, DELETE.
  • Consultas Simples: SELECT, FROM, WHERE.
  • Junções (INNER JOIN, LEFT/RIGHT JOIN).
  • Agregação e Agrupamento (GROUP BY, HAVING).
  • Sub-queries.
