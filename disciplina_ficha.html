Objetivos de Aprendizagem

No final desta unidade curricular, o estudante deverá ser capaz de:

  • Compreender os conceitos fundamentais de sistemas de gestão de bases de dados.
  • Desenhar modelos conceptuais (ER) e lógicos (Relacional).
  • Aplicar regras de normalização para evitar redundância.
  • Utilizar a linguagem SQL para criação (DDL) e manipulação (DML) de dados.
